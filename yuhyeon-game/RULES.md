# 유현이 키우기 — 게임 규칙 설계서

> 이 파일은 "게임의 설명서"예요. 코드를 고치기 전에 여기서 규칙부터 정해요.
> 실제 숫자는 `index.html` 맨 위 `CONFIG` / `FOODS` / `단계표` 에 그대로 들어가 있어요.

## 1. 캐릭터

- 이름: **유현**
- 그림: 직접 그린 PNG로 교체 가능 (아래 9번 참고). 지금은 임시 SVG 캐릭터.

## 2. 호감도

| 항목 | 값  |
| ---- | --- |
| 시작 | 50  |
| 최소 | 0   |
| 최대 | 300 |

### 호감도 단계

| 점수      | 단계                 |
| --------- | -------------------- |
| 0 ~ 19    | 😠 너 싫어           |
| 20 ~ 59   | 😌 아는 사이         |
| 60 ~ 99   | 🙂 관심있음          |
| 100 ~ 149 | 😊 친해짐            |
| 150 ~ 199 | 🤗 항상 만나는 사이  |
| 200 ~ 249 | 😍 좋아함            |
| 250 ~ 299 | 🥰 최애              |
| 300       | 👑 호감도 정복 완료! |

시작값 50은 "아는 사이"예요.

## 3. 음식

| 음식        | 호감도 | 배부름        | 상점 가격 |
| ----------- | ------ | ------------- | --------- |
| 🥩 스테이크 | +8     | +25           | 12 코인   |
| 🍬 마카롱   | +4     | +15           | 8 코인    |
| 🍇 포도     | +2     | +10           | 4 코인    |
| 🧊 얼음     | 0      | **변화 없음** | 2 코인    |
| 🪨 돌맹이   | −2     | **−10**       | 1 코인    |

**취향은 숨김.** 한 번도 안 먹여본 음식은 도감에 `???` 로 표시되고,
먹여보면 그때 점수가 공개돼요.

> 🪨 돌맹이는 호감도를 깎지만 **배부름을 −10 해줘요.** 배가 불러서 밥을 못 줄 때
> 일부러 돌맹이를 던져 배를 꺼뜨리는 전략이 가능해요.

## 4. 호감도가 깎이는 규칙 (감소 2종)

적용 순서대로 계산해요.

1. **질림** — 같은 음식을 연속 5번째로 주면 → 그 판은 **호감도 0**
   - 다른 음식을 주면 연속 횟수가 1로 초기화돼요.
2. **호감도 250 이상** ("최애" 단계부터) → 상승치 **절반**

**배부름은 호감도에 아무 영향이 없어요.** 배부름은 "더 못 먹게" 하는 역할만 해요.

> 게임 화면 위쪽에 **"스테이크를 지금 주면 +N"** 이 항상 표시되고,
> 반토막이 걸렸으면 그 이유까지 같이 나와요.
> 계산 과정 전체는 아래 "계산 기록"에서 볼 수 있어요.

**마이너스 음식(돌맹이)은 절반 적용 안 해요.** 벌은 항상 그대로 −2.

## 5. 배부름

배부름은 **한 번에 몰아서 먹이는 것만 막아요.** 호감도 계산에는 전혀 관여하지 않아요.

| 항목 | 값                                                  |
| ---- | --------------------------------------------------- |
| 범위 | 0 ~ 100                                             |
| 100  | **배부름을 올리는 음식**은 못 먹음 ("배불러…")      |
| 회복 | 1분에 10씩 자동 회복 (**10분**이면 완전히 배고파짐) |

배부름이 100이어도 **얼음(0)과 돌맹이(−10)는 줄 수 있어요.**
배부름을 올리지 않는 음식이라 막을 이유가 없거든요.
급할 때 돌맹이를 던져 배를 꺼뜨리는 것도 가능해요. (호감도 −2는 감수)

## 6. 방치 페널티

- **2시간**마다 쓰다듬어주지 않으면 호감도 **−4**
- 앱을 꺼놔도 시간은 흘러요. (마지막 쓰다듬은 시각을 저장해뒀다가, 켤 때 계산)

## 7. 코인 & 상점

- **쓰다듬기** → 코인 +1
  - ⚠️ 무한 연타로 코인을 무한히 벌 수 있어서 **2초 쿨타임**을 넣었어요. (빼도 됨)
  - 쓰다듬으면 호감도는 안 오르지만 **방치 타이머가 초기화**돼요.
- **출석체크** — 하루에 처음 켤 때 🥩 스테이크 1개 + 🪙 코인 20
- 코인으로 상점에서 음식 5종 전부 구매 가능
- 시작할 때 주는 것: 코인 10, 스테이크 1 · 마카롱 1 · 포도 5 · 얼음 3 · 돌맹이 3

## 8. 처음부터 다시 시작

「🔄 처음부터」 버튼 → **예 / 아니오 확인 창**이 뜨고, "예"를 눌러야 초기화돼요.

> 브라우저에 원래 있는 `confirm()` 창은 앱 안에 넣어서 볼 때 막히는 경우가 있어요.
> (그래서 예전 버전에서 버튼이 아무 반응이 없었어요.) 그래서 확인 창을 직접 만들었어요.

초기화해도 **출석체크 기록은 남겨둬요.** 안 그러면 초기화를 반복해서
출석 보상을 하루에 여러 번 받을 수 있거든요.

## 9. 그림 교체하는 법

게임 화면 아래 **「🎨 그림」 버튼**을 누르면 표정 8종이 나옵니다. 각 표정마다 방법이 두 가지예요.

### 방법 A — 📁 사진에서 (갤러리 그림 넣기)

「📁 사진에서」 → 파일 선택 → 끝.

- 투명 배경 PNG 로 그리면 제일 예뻐요
- 어떤 크기로 넣어도 **가로세로 256px 이하로 자동 축소** 후 webp(미지원 시 png)로 저장

### 방법 B — ✏️ 직접 그리기 (폰에서 손가락으로)

「✏️ 직접 그리기」 → 손가락으로 그리기 → 「저장」.

- 색 10가지, 붓 굵기 3단계, 지우개, 되돌리기(최근 10단계), 전부 지우기
- 배경은 자동으로 **투명**하게 저장돼요
- 이미 넣어둔 그림이 있으면 불러와서 **이어 그릴 수 있어요**
- 파일 선택창이 필요 없어서 **어떤 환경에서도 동작**합니다

### 공통

- 넣은 그림은 그 기기의 브라우저에 저장돼요 (`yuhyeon-images-v1`)
- **「기본」 하나만 넣어도 돼요.** 안 넣은 표정은 기본 그림으로 대신 나와요
- 「🧽」 버튼으로 지우면 원래 임시 캐릭터로 돌아가요
- 저장 공간이 꽉 차면 그림은 화면에 그대로 두되, 계산 기록에 "저장은 안 됐다"고 알려줘요

### 코드로 넣기 (파일로 배포할 때)

`yuhyeon-game/images/` 에 PNG 를 넣고 `index.html` 의 `캐릭터_그림` 에서 경로를 지정합니다.
게임 안에서 넣은 그림이 이 설정보다 우선해요.

### 표정 8종

| 이름       | 언제 나오는지                    |
| ---------- | -------------------------------- |
| `idle`     | 평소 (기본)                      |
| `happy`    | 마카롱·포도 먹을 때, 쓰다듬을 때 |
| `love`     | 스테이크 먹을 때                 |
| `confused` | 얼음 먹을 때                     |
| `disgust`  | 돌맹이 먹을 때                   |
| `eating`   | 먹는 순간 (0.7초)                |
| `bored`    | 질렸을 때, 배부를 때             |
| `sad`      | 아직 안 씀                       |

## 9-1. 화면에 있는 안내

- 게이지 아래 줄에 **"지금 스테이크를 주면 +N"** 이 항상 표시돼요.
  반토막이 걸려 있으면 그 이유(호감도 250 넘음 / 배부름 70 넘음)까지 같이 나와요.
- 화면 맨 아래에 **버전**이 표시돼요. 업데이트가 도착했는지 여기서 확인할 수 있어요.
