# 이 폴더에 그림을 넣으세요

직접 그린 **투명 배경 PNG** 파일을 이 폴더에 넣으면 돼요.
(정사각형, 512 × 512 픽셀 권장)

그다음 `../index.html` 을 열어서 맨 위 `캐릭터_그림` 부분을 이렇게 고치면 끝!

```js
const 캐릭터_그림 = {
  idle:     "images/유현_기본.png",     // ← null 대신 파일 이름
  happy:    "images/유현_기분좋음.png",
  love:     null,                        // 안 그린 건 null 그대로 두면 임시 캐릭터가 나와요
  ...
};
```

## 필요한 표정 8종

| 이름       | 언제 나오는지                        |
| ---------- | ------------------------------------ |
| `idle`     | 평소 (기본)                          |
| `happy`    | 마카롱·포도를 먹었을 때, 쓰다듬을 때 |
| `love`     | 스테이크를 먹었을 때                 |
| `confused` | 얼음을 먹었을 때                     |
| `disgust`  | 돌맹이를 먹었을 때                   |
| `eating`   | 먹는 중 (0.7초)                      |
| `bored`    | 질렸을 때, 배부를 때                 |
| `sad`      | (아직 안 씀 — 나중에)                |

다 안 그려도 괜찮아요. `idle` 하나만 넣어도 돼요!
